# ADR index

Architecture is what is hard to change. ADRs capture those invariants—intents we do not plan to reverse without a deliberate new decision—without freezing libraries, layouts, schemas, or other easy implementation choices. We have not locked the first set yet; the records below are drafts while we work them into shape.
